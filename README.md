# tugas-pemrogaman-web
Smart Money adalah program berbasis website yang dibuat untuk membantu pengguna mengelola keuangan pribadi dengan lebih mudah dan teratur. Program ini memungkinkan pengguna mencatat jumlah uang yang dimiliki, uang masuk, dan uang keluar, serta melihat rekap keuangan dalam periode mingguan, bulanan, maupun tahunan.
Program ini dibuat menggunakan HTML, CSS, dan JavaScript. Desainnya menggunakan warna soft pink agar terlihat sederhana, menarik, dan nyaman digunakan. Smart Money cocok digunakan oleh mahasiswa maupun masyarakat umum untuk memantau penggunaan uang sehari-hari.
Selain itu, program ini membantu pengguna mengevaluasi pemasukan dan pengeluaran melalui rekap keuangan yang tersedia.
